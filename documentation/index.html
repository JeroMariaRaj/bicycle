VELOMETRIX – Bicycle Fitting & Performance Studio

VELOMETRIX is a state-of-the-art, commercial-grade HTML5 website template and interactive frontend Rider Dashboard crafted specifically for professional bicycle fitting laboratories, cycling biomechanists, endurance sports clinics, and aerodynamic performance centers.

Zero Build Step

Runs directly out of the box in any modern browser without requiring Node.js, npm, or compiler configurations.

Frontend Dashboard

Complete 9-page Rider Portal with live Chart.js charts, bike garage CRUD, fit comparison tool, and printable PDF sheets.

Dark Mode & RTL

Built-in theme persistence (Light, Dark, and OS sync) along with full Right-to-Left bidirectional language layout.

2. Quick Start Guide

Because VELOMETRIX is 100% frontend-only, you can view and test it immediately:

1 Local Double-Click / Direct File Opening

Open index.html directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari. All pages and interactive scripts are self-contained.

2 Optional Local Web Server

If you prefer running a local HTTP server:

# Using Python:
python -m http.server 8000

# Using Node.js npx:
npx serve .

# Then open http://localhost:8000 in your browser

5. Dark Mode & RTL Support

Both public pages and dashboard screens support dark mode and Right-to-Left (RTL) mode. State is automatically persisted in localStorage.getItem('velometrix_theme') and localStorage.getItem('velometrix_direction'). 

// Programmatic toggles via theme.js:
window.VelometrixTheme.setTheme('dark');    // or 'light'
window.VelometrixTheme.toggleRTL();          // toggles dir="rtl" on <html>

6. Mock Data & LocalStorage Schema

The core data store lives in assets/js/mock-data.js. All user modifications (booking sessions, registering bikes, editing profile metrics) persist to browser localStorage under the prefix velometrix_.

Storage Key Default Constant Description
velometrix_profile DEFAULT_RIDER_PROFILE Rider contact, anthropometrics (height, inseam), and FTP.
velometrix_appointments DEFAULT_APPOINTMENTS Upcoming, completed, and canceled fitting sessions.
velometrix_bikes DEFAULT_BIKES Bicycle garage fleet (models, frame sizes, saddles, cranks).
velometrix_fitHistory DEFAULT_FIT_HISTORY 4 historical sessions with 8 millimeter measurements each.

7. Adding Services & Articles

To add a new fitting service or scientific knowledge article, simply edit assets/js/mock-data.js. The catalog pages (services.html, blog.html) and dynamic details pages (service-details.html?id=..., blog-details.html?id=...) will automatically render the new entries. 

// Example: Adding to VELOMETRIX_SERVICES in assets/js/mock-data.js
{
  id: "gravel-cockpit-fit",
  title: "Gravel & Ultra-Endurance Optimization",
  category: "Cycling Optimization",
  price: 280,
  duration: "1.75 Hours",
  image: "assets/images/services/service-mtb-fit.jpg",
  shortDesc: "Vibration isolation and multi-hand position reach optimization for unpaved terrain.",
  overview: "Extended gravel racing requires a balanced compromise between aero tuck and upper-body fatigue prevention...",
  whoIsFor: ["Unbound Gravel competitors", "Bikepackers", "Multi-surface riders"],
  procedure: [
    { step: 1, title: "Handlebar Flare & Hood Ergonomics", desc: "Align brake levers with neutral wrist angle in drops." }
  ],
  outcomes: ["50% reduction in ulnar nerve palsy", "Stable handling through loose gravel"],
  faqs: [
    { q: "Should I fit with loaded bags?", a: "Yes, bring your standard frame bag setup." }
  ]
}

8. Production Deployment

VELOMETRIX is 100% static HTML5/CSS/JS. It can be hosted on any web server:

  • Netlify / Vercel: Drag and drop the root folder into the dashboard.
  • GitHub Pages: Push to a GitHub repository and enable Pages from the main branch.
  • Apache / NGINX: Upload all files to your public_html or /var/www/html folder.
